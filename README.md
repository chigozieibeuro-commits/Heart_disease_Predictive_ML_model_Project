Heart Disease Prediction API 

About the Project

This project uses Machine Learning to predict the likelihood of heart disease based on patient health data. I built the model using Python and Scikit-learn and integrated it with FastAPI to make predictions through an API.

I also used PostgreSQL for database management and Docker to containerize the application.

Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn
- FastAPI
- PostgreSQL
- Docker
- Git & GitHub

Project Features

- Predicts heart disease using a trained ML model.
- Accepts and validates input through FastAPI.
- Connects to PostgreSQL for data storage.
- Uses Docker to run the application in containers.

How to Run



Navigate to the project folder:

cd heart-disease-prediction

Build and run the application using Docker:

docker build --no-cache

docker compose up 

What I Learned
